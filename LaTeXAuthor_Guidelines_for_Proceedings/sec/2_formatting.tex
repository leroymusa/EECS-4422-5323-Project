\section{Dataset and Methods}

\subsection{Dataset description}

The dataset contains ten UV-C images of saliva deposits on five substrates (aluminum, steel, white wood, PVC, and wood) with both wet and dry patches. Each frame is accompanied by a binary mask that highlights four roughly centralized saliva patches. We treat the first eight images as the tuning set and reserve the final two images for blind testing; the masks only cover the salient regions, so every method must operate in an unsupervised fashion while relying heavily on color, contrast, and spatial locality.

\begin{itemize}
  \item \textbf{Imaging:} High-contrast UV-C photography with fluorescent saliva to accentuate deposits across heterogeneous materials.
  \item \textbf{Ground truth:} One binary mask per image that marks four foreground regions, which guide plausibility filters and evaluation.
  \item \textbf{Split:} Images 1-8 serve for parameter tuning, and 9-10 are used to report unseen performance.
  \item \textbf{Challenge:} The small dataset prevents supervised training, so all methods rely on heuristics shaped by saliva brightness and location.
\end{itemize}

\subsection{Method A: MATLAB thresholding pipeline}

Method A is a lightweight MATLAB pipeline that maximizes recall through contrast enhancement and biased thresholding. We convert RGB frames to luminance using ITU-R BT.601 weights, apply CLAHE to normalize local contrast, and tune a bias for Otsu's threshold so that the resulting binary mask includes more saliva when the default threshold underestimates the foreground.

\subsubsection{Pre-processing}

\begin{itemize}
  \item \textbf{Luminance conversion:} Each pixel's RGB values are aggregated as \(0.299R + 0.587G + 0.114B\), producing the grayscale images shown in Figures 2a and 2b.
  \item \textbf{CLAHE:} Contrast Limited Adaptive Histogram Equalization (Figure 2c) equalizes local histograms while limiting noise amplification, making the threshold more stable.
\end{itemize}

\subsubsection{Training}

Otsu's threshold pulls a level that minimizes intra-class variance on the bimodal histogram (Figure 2d), but it can underestimate saliva in uneven lighting. We therefore learn a bias factor that adjusts the threshold before binarization. The bias is updated as

\begin{equation}
  t_{\text{new}} = t_{\text{otsu}} \times (1 - \text{bias}),
\end{equation}

and we sweep this bias on the tuning set to maximize the Dice coefficient. Plausibility filters then remove regions that are either too large (non-saliva) or too small (noise) and reward blobs near the geometric center of the annotated patches. Figure~\ref{fig:method_a_steps} from Felipe’s folder summarizes the six labeled stages (a–g) that produce the cleaned mask.

\subsubsection{Testing and post-processing}

With the tuned bias (Figure~\ref{fig:bias_tuning}), images 9 and 10 are processed without consulting the ground truth. The same area-based filters remove unrealistic regions, but without direct knowledge of the annotated centroids, we judge centrality relative to the image center. Morphological closing (erosion followed by dilation) closes small gaps (Figure~\ref{fig:method_a_steps}f), and the final mask is compared to the blind ground truth for precision/recall reporting (Figure~\ref{fig:method_a_steps}f).

\subsection{Method B: placeholder}

Method B was reserved for future experimentation and remains unimplemented. The emphasis of this draft is on Methods A, C, and the probabilistic extension described in Method D.

\subsection{Method C: exploratory k-means}

Method C clusters RGB pixels with k-means. Each run uses ten random starts, and we select the solution with the smallest compactness (within-cluster sum of squares). The centroid with the highest luminance \(0.299R + 0.587G + 0.114B\) is labeled as saliva, and the corresponding pixels form a binary mask that is cleaned with morphological opening and closing.

\subsubsection{Pre-processing}

No pre-processing beyond using raw RGB pixels was required—the UV-C contrast is already sufficient to separate saliva from the background, and Gaussian or median filters degraded performance.

\subsubsection{Clustering}

\begin{itemize}
  \item Ten runs per image keep the best result by compactness.
  \item The brightest center identifies saliva, and its assigned pixels become the foreground mask.
  \item Each mask is cleaned with morphological operations (opening and closing) to remove speckles and fill holes.
\end{itemize}

Experiments with \(K=2,3,4,5\) show that \(K=3\) is a good precision/recall balance, \(K=4\) retains high recall while sacrificing some precision, and higher values lose too much recall. \subsection{Method D: probabilistic Gaussian mixture model}

Method D upgrades the k-means clusters with a full Gaussian mixture model that quantifies uncertainty and chooses the most probable segmentation. Each pixel \(\mathbf{x}_i = (R_i, G_i, B_i)^\top\) is modeled as

\[
  p(\mathbf{x}_i \mid \Theta) = \sum_{k=1}^K \pi_k \, \mathcal{N}(\mathbf{x}_i \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)
\]

with \(K \in \{3,4\}\), full covariances \(\boldsymbol{\Sigma}_k\), and mixture weights \(\pi_k\). Expectation–Maximization is handled by \(\texttt{sklearn.mixture.GaussianMixture}\), while our contribution is the multi-start setup, initialization, and model selection via pseudo-log-likelihood.

\subsubsection{Pre-processing}

\begin{itemize}
  \item The images remain in RGB space and are reshaped into pixel arrays so the GMM learns the native color distribution.
  \item Candidate means \(\boldsymbol{\mu}_k^{(0)}\) come from Method C's k-means centers, helping EM start near saliva/background splits.
  \item No additional smoothing or filtering is applied, keeping preprocessing comparable to the other pipelines.
\end{itemize}

\subsubsection{Training and model selection}

\begin{itemize}
  \item For each image and each \(K\), we run \(n_{\text{runs}} = 10\) independent GMM fits mixing k-means seeds with random starts to explore multiple basins of attraction.
  \item Each fit returns

  \[
    \text{PLL}(\Theta) = \sum_{i=1}^{N} \log p(\mathbf{x}_i \mid \Theta),
  \]

  which we use to select the most probable solution because EM only guarantees local convergence.
  \item EM yields responsibilities

  \[
    \gamma_{ik} = p(z_i = k \mid \mathbf{x}_i, \Theta^*),
  \]

  so the foreground probability map \(P_{\text{FG}}(\mathbf{x}_i)\) is given by \(\gamma_{ik_{\text{fg}}}\), where \(k_{\text{fg}}\) is the component with the highest luminance \(Y_k = 0.299R_k + 0.587G_k + 0.114B_k\).
\end{itemize}

\subsubsection{Mask construction and evaluation}

\begin{itemize}
  \item We threshold the probability map at 0.5, yielding a soft mask that is refined with morphological opening and closing to remove noise.
  \item Accuracy, precision, recall, Dice, and the pseudo-log-likelihood of the selected model are recorded for every image and every \(K\); these per-image metrics feed the results summary and demonstrate how likelihood-guided selection aligns with segmentation quality.
\end{itemize}

This fully probabilistic workflow keeps the interpretability of k-means while adding soft assignments, likelihood-based selection, and quantified uncertainty via the posterior probability maps.
